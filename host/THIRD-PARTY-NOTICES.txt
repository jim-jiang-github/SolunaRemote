SolunaRemote integrated host

The embedded Windows and locally built macOS hosts use the modified Sunshine
source in third-party/Sunshine. The macOS host is built locally and ad-hoc
signed; it is not an official Sunshine release.

Sunshine is GPL-3.0 software. Preserve its license and provide complete
corresponding source, dependency sources and build scripts as required when
redistributing this binary. A source URL or license alone is not a substitute
for satisfying the complete corresponding source obligations.

SolunaRemote builds Sunshine without its tray and independent web interface.
The soluna-stream client uses moonlight-common-c, FFmpeg and SDL directly,
without requiring a separately installed client application.
